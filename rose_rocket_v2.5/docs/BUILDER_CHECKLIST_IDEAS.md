# Builder's Implementation Checklist — archived idea

Non-binding. Not part of Rose Rocket v2.5 standing rules.

Those ideas are not the newspaper's cadence, voice, or send gate. Current rules live in `rose_rocket_v2.5/rules/CURRENT_RULES.md`.
